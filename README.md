# DVT static website

Open `dist/index.html` or serve `dist` with any static web server. No installation or build step is required. `node build.cjs` regenerates the four HTML pages.

The complete site includes 21 pages plus three URL aliases: Home, all services, 8 service detail pages, About Us, How We Work, Our Team, Mission & Vision, Our Values, Testimonials, Industries, Careers, Contact, Latest News, and Privacy Information. See `page-inventory.json` and `REFERENCE-COVERAGE.md` for the full coverage.

The contact form includes all six reference fields and opens a validated email draft addressed to careers@dvtworld.com. It does not send email from a server. Visitors review and send the message in their email application.

The design follows https://www.castleskysoft.com/: photo banner, service tiles, partnership section, five-stage project process, client approach, and detailed footer. DVT's name and brand palette are retained. Office photograph: https://unsplash.com/photos/1497366216548-37526070297c (served from images.unsplash.com); illustrative stock imagery, not a DVT office photo.

The supplied logo is included at `dist/assets/logo.png` and appears in the header and footer on every page.

Service descriptions are proposed website copy. Review them against the company's actual offerings before public release. Google Fonts are optional external resources; the site falls back to sans-serif offline.
